FINAL EXERCISES — BEGINNER GUIDE
Topic: Model Persistence and Basic Deployment Using Flask API or Streamlit

IMPORTANT:
The files you uploaded contain the lesson and exercise instructions, but they do not include the original train_model.py, app.py, or streamlit_app.py. This folder is a complete sample solution you can run and study. The training data is sample/demo data only.

STEP 1 — Install Python
Check that Python is installed:
    py --version

STEP 2 — Open this folder in VS Code
Extract the ZIP file first. In VS Code, choose File > Open Folder, then select ML_Final_Exercise_Solution.

STEP 3 — Open the VS Code terminal
Choose Terminal > New Terminal.

STEP 4 — Install the needed libraries
Run:
    py -m pip install -r requirements.txt

STEP 5 — Run Exercise 1 (Model Persistence)
Run:
    py train_model.py

Expected:
- It saves student_pass_model.joblib.
- It loads that saved model.
- It makes three predictions for 2, 4, and 7 study hours.
- The exact results depend on the sample training data and trained model.

WHAT TO EXPLAIN:
joblib.dump() saves the trained model to a file.
joblib.load() loads the saved model.
The model can predict again without being trained from scratch because its learned structure is saved in the file.

STEP 6 — Run Exercise 2 (Flask API)
First make sure you already ran train_model.py so student_pass_model.joblib exists.
Run:
    py app.py

Keep this terminal open. The API runs at:
    http://127.0.0.1:5000

TEST WITH A SECOND VS CODE TERMINAL:
Run this one-line command:
    curl.exe -X POST http://127.0.0.1:5000/predict -H "Content-Type: application/json" -d "{\"study_hours\":5,\"attendance_percentage\":90}"

It should return JSON with study_hours, attendance_percentage, and prediction.
To test validation, try attendance_percentage 120. It should return an error because attendance must be between 0 and 100.

IMPORTANT NOTE FROM THE EXERCISE:
The model currently uses only study_hours. Attendance is checked and returned in the response, but does NOT affect the prediction. To make attendance affect predictions, the training data and model must be updated and retrained using both inputs.

STEP 7 — Run Exercise 3 (Streamlit Interface)
Stop the Flask app with Ctrl+C.
Run:
    py -m streamlit run streamlit_app.py

A browser should open. Enter a student name, enter study hours, and click Predict.

STEP 8 — What each file does
train_model.py: trains and saves the model, then tests three predictions.
student_pass_model.joblib: the saved trained model generated by train_model.py.
app.py: receives JSON input through a Flask API and returns a JSON prediction.
streamlit_app.py: displays a simple web interface.
requirements.txt: lists the Python libraries to install.

TROUBLESHOOTING
- If 'py' is not recognized, try 'python' instead of 'py'.
- If a module is missing, run: py -m pip install -r requirements.txt
- If student_pass_model.joblib is missing, run: py train_model.py first.
- If the terminal says the address/port is already in use, stop the other app with Ctrl+C.
- Keep the terminal running while testing the Flask API or Streamlit page.
