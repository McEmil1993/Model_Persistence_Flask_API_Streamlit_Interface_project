Student pass predictor

Test both exercises here. This prototype uses the same trained models as your Python files, running in the browser.

Inputs: student name, study hours (0 to 12).
Output: Pass or Fail message, chance of passing, explanation, chart.

How was this prediction generated?

The app loads a Logistic Regression model that was already trained and saved as student_pass_model.joblib, so no training happens here. The model turns the study hours into a pass probability. At 50% or higher the result is Pass; otherwise it is Fail. For this student:
