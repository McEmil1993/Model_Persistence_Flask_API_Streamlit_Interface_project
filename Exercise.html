Student Pass Prediction

Subject: IT Elective 3 - AI: Machine Learning

Lesson: Model Persistence and Basic Deployment

Exercise 1: Model Persistence

  1. Train a machine learning model using train_model.py.
  2. Save the model using joblib.
  3. Load the saved model without retraining it.
  4. Test predictions for 2, 5, and 8 study hours.
  5. Explain why saving a trained model is useful.

Exercise 2: Flask API

  1. Run the Flask application.
  2. Send a POST request to /predict.
  3. Provide study_hours and attendance_percentage as JSON.
  4. Check the returned prediction and validation errors.
  5. Explain what the API returns.

Exercise 3: Streamlit Interface

  1. Run the Streamlit application.
  2. Enter a student's name.
  3. Enter the number of study hours.
  4. Click Predict Result.
  5. Record the result and explain the output.

Reminder: This project uses a small sample dataset for learning. Attendance is validated by the API but is not used by the model to make predictions.
